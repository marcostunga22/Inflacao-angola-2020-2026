# Inflação em Angola (2020-2026) - Análise com Excel

Análise da trajetória da inflação homóloga e média anual em Angola, de 2020 a 2026, com foco na interpretação para o poder de compra das famílias.

## Objetivo
Entender como a inflação se comportou em Angola nos últimos 7 anos:
- Quando acelerou?
- Quando desacelerou?
- O que isso significa na prática?

## Fonte dos Dados
- INE Angola
- BNA - Banco Nacional de Angola
- Nota: 2026 é projeção / estimativa

## Ferramentas
- LibreOffice Calc / Excel
- Gráfico de linhas para trajetória
- Tabela dinâmica para variação YoY

## Principais Insights

1. 2022 - Alívio
A inflação de fim de período caiu de 27,0% (2021) para 13,8% (2022).

2. 2024 - Pico
A inflação média anual chegou a 28,2% e a de fim de período a 27,5%.
Foi o ano mais pesado para o poder de compra.

3. 2025-2026 - Desaceleração
A inflação cai para 15,7% em 2025 e 13,1% em 2026 (projeção).
Os preços continuam a subir, mas a subir mais devagar.
